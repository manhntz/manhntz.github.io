YT Uploader

YT Uploader is a personal command-line tool that uploads videos to the YouTube channels owned by the person running it. It uses the YouTube Data API v3 and Google OAuth 2.0 to publish videos, set titles, descriptions, tags and thumbnails on those channels.

The tool is operated by its owner only. It is not offered to the public, does not have user accounts, and does not collect data from anyone other than the channel owner who signs in.
